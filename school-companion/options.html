LockIn School Companion

This tells LockIn whether Canvas or Edgenuity is open in this Chrome profile. That is all it does, and all it can do.

Before you turn this on

Many school Chrome profiles are managed by the district, and many districts do not allow extensions to be installed on them. This package is for the case where installing it is allowed or approved by your school.

LockIn will not help you get around an administrator setting, and it does not need this extension — everything else works without it.

What it sends

{
  provider: "edgenuity",
  activity: "active",
  startedAt: 1773251400000,
  lastActiveAt: 1773251460000
}

Four facts, once a minute, to LockIn on this computer only (127.0.0.1). It has no permission to reach anything else.

What it cannot send

  • Assignments, lessons, questions, answers or grades — it has no content script and no scripting permission, so it cannot read a page at all.
  • Web addresses. It reads a tab's address to tell Canvas from Edgenuity from neither, and the message it sends has no field to put one in.
  • Cookies, logins or session data. It never touches them.

Pair with LockIn

In LockIn, open Integrations → School Companion and choose Show pairing code. Paste it here.

Turn it on

Off by default. Turning it off stops everything immediately; nothing is kept once LockIn's service restarts, because the context is only ever held in memory.
